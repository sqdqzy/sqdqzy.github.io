# 林间小屋 · Forest Cabin

一个**完全程序化生成**的 3D 网页场景：北方山区夏末初秋的一间原木农舍，坐落于白桦与云杉混交林中。
没有一张外部贴图、没有一个外部模型——地形、木屋、树木、水面、天空、尘埃、调色全部由代码在浏览器里实时生成。

默认是「黄金时刻」：太阳在东南侧 18° 的低角度，穿过林间空地把暖光斜打进院子，木屋窗口透出暖黄的光，烟囱飘着一缕炊烟，浮尘在光柱里漂。

---

## 快速开始

ES module 必须走 HTTP（不能双击 `index.html`，`file://` 会被 CORS 拦住）：

```bash
# 方式一：Windows 双击
启动预览.cmd

# 方式二：命令行
node serve.mjs 8123
# 然后打开 http://127.0.0.1:8123/
```

**不需要 `npm install`**：three.js r185 已完整内联在 `vendor/three/`，整站离线可用、零网络请求。

### URL 参数

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `preset` | `dawn` `morning` `golden` `overcast` `dusk` `night` | 直接进入某个时段 |
| `q` | `low` `medium` `high` `ultra` | 画质档（默认 `high`，会记入 localStorage） |
| `cam` | `free` | 以自由漫游模式启动（默认电影运镜） |
| `shot` | `1` | 截图模式：隐藏全部界面与黑边 |

例如 `http://127.0.0.1:8123/?preset=night&q=ultra`

### 操作

| 操作 | 功能 |
| --- | --- |
| 拖动 / 滚轮 | 旋转、缩放（自由漫游） |
| `C` | 电影运镜 ⇄ 自由漫游 |
| `空格` / `←` `→` | 下一镜 / 上一镜 |
| `1`–`6` | 切换时段（破晓 / 清晨 / 黄金时刻 / 阴天 / 黄昏 / 月夜） |
| `H` | 隐藏 / 显示界面 |
| `F` | 全屏 |
| `R` | 重置视角 |
| `P` | 暂停时间（截图用） |

## 场景里有什么

**地形与水体**
- 240×240 m 程序化地形：分形噪声起伏 + 远处环山（把视线封在森林里）+ 池盆凹陷 + 小径压平 + 院子平整（院子内高差 < 5 cm，木屋不悬空）
- 一条从西南林间蜿蜒到正门的碎石小径，路中央被踩得更亮，边缘用顶点 alpha 向草地渐隐
- 池塘：自定义着色器水面——双层滚动法线、菲涅尔天空反射、太阳/月光高光、按水深着色、手写 FogExp2；末尾内联 tonemapping/colorspace chunk，**开关后处理都色彩正确**
- 岸边芦苇/香蒲、半浸石块、浮萍漂移

**木屋与院落**
- 原木叠砌墙体：每层四根同高交错，四面转角外伸 0.50 m；圆木山墙逐层收细到屋脊 + 三角补板
- 石砌地基（埋深 0.60 m）、木瓦屋顶（行距 0.30 m、屋脊压条、封檐板、露出椽头）、真实切洞的门窗
- 门廊：木平台、立柱斜撑、车削式栏柱、三级石阶、挂灯；石砌烟囱 + 74 粒炊烟
- 窗光＝渐变 emissiveMap（底部亮、顶部暗 + 边缘收暗）+ 手工玻璃法线 + 内侧暗窗棂；白天是暗房间里的灯，夜里点亮，强度由 `nightFactor` 驱动
- 院落道具：水井（辘轳/木桶）、柴垛与斧头、分叉栅栏、三垄菜畦 + 稻草人、独轮车、接雨水桶、牛奶罐、信箱、鸟屋、晾衣绳（布料随风摆）、靠墙农具、11 块踏步石、蜂箱、三盏木柱灯笼

**森林**
- 五类树：云杉、松、白桦（成丛）、阔叶（交叉叶片面片，逆光透亮）、枯木倒木
- 树冠用 `warpedFbm` 做角向半径抖动 + 底缘起伏下坠，破掉「叠盘子」感；三级 LOD（近模 / 远模 / 树墙）
- 地被：草簇 79,560 实例（单 draw call）、灌木、蕨类、苔藓、野花、毒蝇伞、树桩、半埋岩石
- **向阳缺口**：从院子朝太阳方位（42°±31°，半径 78 m）的扇形内只留草与低矮灌木、不放乔木——真实林间木屋总有一片朝阳空地，这也是直射光能落进屋前的物理前提

**氛围**
- 6 套时段预设是一套**完整状态机**：太阳角度/颜色/强度、环境光、半球光、补光、天空散射、雾、云、曝光、辉光、调色参数、体积光、粒子配额、夜光因子、风力——切换时全部字段以 1.8 s 缓入缓出平滑插值，可被打断
- 天穹（大气散射）、太阳/月亮平行光（阴影相机锁定院子）、半球环境光、反向补光、成团云壳
- 粒子：光柱里的浮尘、花粉、翻滚落叶、各自相位闪烁的萤火虫、星空、远处飞鸟、贴地薄雾——全部在相机周围循环复用

**画面**
- 后处理：HDR（HalfFloat）→ 屏幕空间体积光束 → UnrealBloom → ACES tone mapping（OutputPass）→ SMAA → 调色（色温/色调/对比/饱和/暗部提亮/暗角/胶片颗粒/色差/锐化）
- 6 段电影运镜：建立镜头、黄金逆光、门前小径、环屋巡游、池塘倒影、檐下仰视——带缓入缓出与手持呼吸噪声，并内置**视线自动清理**（射线检测机位是否陷在树冠里，会自动抬高/逼近）
- 电影黑边、界面错峰淡入、自适应像素比（掉帧自动降采样，回升）

## 架构

严格分层，模块之间**互不 import**，全部由 `src/main.js` 装配——改任何一个模块都不会破坏别人。

```
index.html            页面外壳：importmap、载入界面、错误兜底、全局 CSS 变量
src/core.js           ★ 共享契约层（唯一权威定义，Lead 维护）
                        · 地形高度 / 法线 / 坡度 / 摆放约束 / 向阳缺口
                        · 世界布局常量（院子、木屋、小径、池塘、正门坐标）
                        · 6 套时段预设 + 预设插值 + 由方位角仰角求太阳方向
                        · 17 种程序化贴图工厂 + 由贴图派生的法线贴图
                        · 风摆顶点着色器补丁（树、灌木、草、布料共用）
src/main.js           装配层 / 控制器：渲染器、相机、运镜、状态广播、性能自适应、调试钩子
src/terrain.js        地形网格、小径、池塘水面、岸边细节
src/forest.js         五类树、LOD 树墙、地被、岩石、蘑菇
src/cabin.js          原木农舍本体（墙体 / 屋顶 / 门窗 / 门廊 / 烟囱 + 炊烟）
src/props.js          院落生活道具
src/sky.js            天穹、太阳/月亮光照、云、日轮辉光、时段状态机
src/particles.js      尘埃 / 花粉 / 落叶 / 萤火虫 / 星空 / 飞鸟 / 薄雾
src/postfx.js         HDR 后处理管线与调色
src/ui.js             控制界面（自建 DOM + 注入样式）
```

**单向数据流**：`sky.js` 是光照状态的**唯一写入者**，每帧把 `state`（与 `TIME_PRESETS` 同构，另附运行时字段 `sunDirection: Vector3` 与 `sunScreen{x,y,visible,strength}`，坐标为 **NDC**）交给 `main.js`，再由 `main.js` 广播给地形、木屋、植被、粒子与后处理。任何模块都不需要知道别人怎么实现。

**降级策略**：`main.js` 用动态 `import()` 分阶段装配，任何模块缺失或抛错都会被捕获、显示在页面上并继续渲染其余部分，不会白屏；后处理每个环节（体积光束 / bloom / SMAA / 调色）也都能独立降级。

## 开发/验收工具

| 文件 | 用途 |
| --- | --- |
| `serve.mjs` | 零依赖静态服务器；附带 `POST /__save?name=x.png` 截图落盘端点（把任意 canvas 帧存进 `shots/`） |
| `tools/analyze.py` | 画面体检：均值/分位亮度、死黑与溢出比例、饱和度、冷暖、九宫格亮度分布、曝光判定 |
| `tools/ascii_view.py` | 把 PNG 转成**不受图片预览归一化影响**的字符亮度图 + 色相图（G/Y/T/R/B/K 占比统计） |

> ⚠ 验收提示：很多图片预览工具会自动提亮/归一化，肉眼看到的「亮度」并不可靠。**请以 `tools/analyze.py` 的数值为准**——本项目的曝光与配色校准全部基于它，`tools/ascii_view.py` 的色相占比还揪出过一次「整帧只剩黄褐色、绿色几乎为 0」的问题。

## 三个关键修复（调试记录）

1. **画布 sRGB 写入**：three 的 ColorManagement 会把 hex 转成**线性**值，早期直接把 `col.r*255` 写进 2D 画布，导致 17 种程序化贴图被二次伽马压暗约 4.6 倍（实测叶簇目标色 (65,96,44) 落盘成 (14,30,6)）。修复后落盘像素与目标色逐字节相等。这是全场景长期欠曝的根因。
2. **调色对比度的端点保持**：旧实现是「绕 0.5 的线性拉伸」，k=1.06 时把 x<0.028 全部压成纯黑（实测特写 22.8% 的死黑）。改为保端点 S 曲线 + 低照度权重后，0.02 → 0.0195 且 [0,1] 单调不减。
3. **太阳屏幕坐标约定**：`sunScreen` 是 NDC 而非 uv，体积光束的发射点曾因此偏到画面外，看起来像「整帧一层均匀暖雾」。现已统一为 NDC（并与独立投影逐位校验一致），后处理侧同时做了 NDC/uv/像素三态自动识别。

## 说明

- three.js r185（`vendor/three`，含 MIT 许可协议）
- 全部贴图由 `<canvas>` 在运行时生成，无外部素材、无网络请求
- 所有随机布局走固定种子的 `makeRng()`，同版本下每次刷新画面一致
- 场景内容（地形/木屋/植被布局）在 `src/core.js` 的 `WORLD` / `CLEARING` / `CABIN` / `PATH` / `POND` / `SUN_GAP` 中集中定义，改这些常量即可整体重排场景
