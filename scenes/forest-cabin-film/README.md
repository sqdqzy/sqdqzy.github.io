# 林间小屋 · Forest Cabin

一个**完全程序化生成**的 3D 森林农舍网页场景。地形、木屋、树木、道具、贴图、天空、粒子、
后处理，全部由代码在浏览器里实时生成——**没有一张外部图片、没有一个外部模型、没有一次网络请求**。

默认是「黄金时刻」：低角度暖光斜切进林子，炊烟从石烟囱升起，窗口透出暖黄的光，
地面浮着逆光里的尘埃，树影打在木屋的墙面上。

---

## 运行

ES module 必须走 HTTP（双击 `index.html` 会被 CORS 拦住）：

```bash
# 方式一：双击 启动预览.cmd
# 方式二：命令行
node serve.mjs 8124
# 打开 http://127.0.0.1:8124/
```

three.js r185 已完整内联在 `vendor/three/`，**离线可用，不需要 npm install**。

### URL 参数

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `preset` | `dawn` `morning` `golden` `dusk` `night` | 进入某个时段 |
| `q` | `low` `medium` `high` `ultra` | 画质档（默认 `high`，记忆到 localStorage） |
| `cam` | `free` | 以自由漫游模式启动（默认是电影运镜） |
| `shot` | 存在即生效 | 截图模式：隐藏界面与黑边 |

例如 `http://127.0.0.1:8124/?preset=night&q=ultra`

### 操作

| 操作 | 功能 |
| --- | --- |
| 拖动 / 滚轮 | 旋转、缩放（自由漫游） |
| `C` | 电影运镜 ⇄ 自由漫游 |
| `空格` / `←` `→` | 上一镜 / 下一镜 |
| `1`–`5` | 破晓 / 清晨 / 黄金时刻 / 黄昏 / 月夜 |
| `H` | 隐藏界面 |
| `F` | 全屏 |
| `R` | 复位视角 |
| `P` | 暂停时间（截图用） |

## 场景里有什么

**地形与水**
- 210 × 210 m 程序化地形：分形噪声起伏 + 远处环山（把视线封在林子里）+ 池塘盆地 + 小径压平 + 院子平整
- 顶点色承担大尺度色斑（草皮 / 枯草 / 湿苔 / 踩实泥土 / 岸边淤泥），贴图承担高频细节，两者相乘
- 池塘：自定义着色器水面——三层错频滚动波纹、菲涅尔天空反射、太阳高光、按水深着色、与场景雾一致

**木屋与院落**
- 干砌石基 → 叠砌原木墙（转角逐层交错咬合外伸）→ 山墙竖板 → 木瓦屋顶（露椽头 / 封檐板 / 屋脊压条）
- 门带横撑与铁铰链、门槛石；窗带木框、窗棂与夜间暖光
- 门廊：平台面板 + 龙骨 + 车削栏杆 + 柱础柱头 + 石阶 + 廊檐
- 石砌烟囱（逐层随机明度）+ 炊烟粒子
- 院落道具：分叉木栅栏、水井（带辘轳与吊桶）、柴垛与斧头、雨水桶与落水管、菜畦、稻草人、晾衣绳、信箱、树桩

**森林**
- 四类树 + 枯木：云杉、松、白桦、阔叶、枯木；两级 LOD（近景高模 / 远景低模）+ 外圈林线树墙封住地平线
- 树冠：分层圆锥（逐顶点径向抖动做锯齿轮廓）/ 叶片卡片球壳分布（近景 46~64 张，小而密）
- 地被：草簇（6.7 万实例，集中在相机看得见的半径内）、灌木、岩石，全部走 InstancedMesh
- 逐实例乘子色做明度 / 冷暖扰动，幅度刻意压在 ±15% 以内——再大就成迷彩了

**氛围**
- 5 套时段预设是一套完整状态机（太阳角度与颜色、环境光、天空散射、雾、曝光、辉光、体积光、夜光强度、风），切换时逐字段平滑插值
- 天穹（大气散射）+ 两层云壳 + 日/月轮辉光 + 星空
- 粒子：炊烟、逆光浮尘（权重 = 视线与太阳的夹角）、夜间萤火虫（各自节奏闪烁）

**画面**
- 管线：HDR 渲染 → 屏幕空间光束（跟随日轮屏幕位置，日轮进画时自动收档）→ UnrealBloom → ACES → SMAA → 调色（锐化 / 色温 / 对比 / 饱和 / 暗部提亮 / 暗角 / 胶片颗粒）
- 6 段电影运镜：建立镜头 / 门前小径 / 逆光林隙 / 环屋巡游 / 池塘 / 檐下仰视，带缓入缓出与手持呼吸噪声
- 自适应分辨率（掉帧降采样，恢复后升回）、电影黑边、界面错峰淡入

## 架构

```
index.html      页面外壳：importmap、载入界面、错误兜底
src/core.js     ★ 共享契约层：地形高度函数、世界布局、程序化贴图与法线贴图、
                几何/实例化工具、风摆顶点着色器补丁、顶点色乘子工具
src/sky.js      大气状态机（唯一的状态写入者）、天穹、云、日月轮、光照
src/terrain.js  地形网格与顶点色、小径踏步石、池塘水面
src/forest.js   树几何构造、摆放与密度场、InstancedMesh、地被层、逆光透射着色器
src/cabin.js    木屋本体 + 挂灯
src/props.js    院落道具
src/atmos.js    炊烟 / 浮尘 / 萤火
src/post.js     后处理管线
src/ui.js       控制界面
```

**单向数据流**：`sky.js` 每帧产出 `state`，`main.js` 广播给其余模块。任何模块都不需要知道别人怎么实现。

**降级策略**：每个模块都跑在 `stage()` 里，失败会被捕获、显示在页面错误面板上，
并继续渲染剩余部分——不会因为一个模块挂掉就白屏。

## 踩过的坑（都写进了对应源码的注释）

1. **albedo 乘两遍** → 整场压黑。`diffuse = material.color × map × vertexColor × instanceColor`，
   贴图已经带着正确颜色时，材质色和顶点色都只能是「乘子」（基准 1.0），不能是 albedo。
2. **浅色细节贴图 × 白色材质 = 骨白色森林**。反光率只能由贴图和材质色中的一个承担。
3. **逆光透射不能只看视线方向**。那一项在同一帧里对全屏所有叶片几乎相同，
   结果是树冠被刷成一块均匀奶油色。必须再乘上「这片叶子自己法线背对太阳的程度」。
4. **院子半径必须 ≥ 树高 / tan(太阳仰角)**。黄金时刻太阳很低，院子太小木屋会整栋落在树影里。
5. **粒子尺寸要用「世界尺寸 × 投影系数」**换算成像素。用经验系数会随远近失控，近处一颗浮尘能糊满整屏。
6. **水面法线的水平分量不能压过垂直分量**，否则菲涅尔逐像素跳变，水看起来像迷彩布。
7. **镜头视线清理要单独判「机位是否就在树冠里」**——过滤掉离机位太近的树，会漏掉正好糊在镜头上的那几株。

## 性能

- 全部重复物件走 InstancedMesh；每批都重算 boundingSphere，否则会被整批误剔除
- 贴图与法线贴图按 key 缓存，重复平铺一律 clone，绝不改共享贴图
- 高画质约 1500 棵树 + 6.7 万丛草 + 52 万岩石实例，总计约 72 万三角面、约 40 个 draw call
- 画质档控制像素比、阴影贴图、树/草密度、地形分段、粒子配额与体积光
- 自适应像素比：帧率掉到 42 以下自动降采样，回到 58 以上逐步升回
